05 / 正式产品设计约束

  • 同一个人、两个身份：Mentor 管理个人成长；Studio 显示相同请求的运行证据。
  • 树是组织形式，图是执行过程：允许返回 Supervisor 再规划，禁止无界递归。
  • 有限制的协作：每轮 request ID、关联 parent ID、消息预算、异常处理、权限隔离。
  • 不要伪造解释：Studio 只展示实际记录的行动、输入输出摘要、工具结果和规则，不声称读出模型内部思维。
  • 隐私：真实成长档案与教材不得作为公开 GitHub 示例数据上传。
